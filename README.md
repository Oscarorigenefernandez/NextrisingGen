# NextGen Rising

**Empowering Children. Supporting Families. Building Futures.**

A youth-led community initiative beginning in New Jersey, focused on supporting children and families through community service, educational opportunities, mentorship, and access to essential resources.

## Website
This repository contains the static website for NextGen Rising, built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Files
- `index.html` — responsive website
- `styles.css` — design and responsive layouts
- `script.js` — mobile navigation and footer year
- `assets/logo.svg` — original brand mark

## Publish with GitHub Pages
Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Important status note
NextGen Rising is currently operating as a community initiative. This website does not represent the project as a registered 501(c)(3) organization and does not solicit donations. Any future formal organization, fundraising, or direct services involving minors should be handled with appropriate adult guidance and legal and child-safety safeguards.
